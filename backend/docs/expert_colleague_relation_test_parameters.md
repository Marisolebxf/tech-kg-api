# 科技专家同事关系测试参数

> 以下数据仅供测试老师执行接口和页面测试，不再预填到页面输入框。

接口：`POST /api/v1/kg-service/expert-colleague-relation`

## 参数要求

- `expert_a_id`：必填，专家 A 的 VID。
- `expert_b_id`：必填，专家 B 的 VID。
- `start_time` 和 `end_time`：可选；填写时必须同时提供，格式为 `YYYY-MM`。

## 页面校验点

- 首次进入页面时，四个输入框均为空。
- 点击“重置参数”后，四个输入框均恢复为空。
- 专家 A 或专家 B 为空时，字段下方显示“请输入专家 A/B”，页面提示“请完善必填项后再执行”，不发起请求。
- 三组数据应分别显示两位专家的共同机构和有效任职重叠时间。
