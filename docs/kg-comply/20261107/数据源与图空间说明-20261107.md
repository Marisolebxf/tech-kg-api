## 4. 行话对照

| 词 | 人话 |
|---|---|
| 图空间 / space | 同一个图库里的独立隔间，数据互不串门 |
| Tag | 节点类型，类似「一类东西一张表」。`enterprise` 是企业，`policy` 是政策 |
| 边 / Edge | 两节点间的连线，表示关系 |
| VID | 节点的身份证号，唯一 |
| 七要素 | 需规画的七类：企业、产业链环节、科研机构、技术（论文/专利/项目）、人才、政策、服务机构 |
| 技术点 | 「技术主题」，例：生物序列比较计算方法。**不是**七要素里的「技术」，本期夹带演示，不并进七要素 |
| M01–M24 | 「24 条必须有的关系」，需规签收过，不能改 |
| B1–B6 | 技术点那层的 6 类关系 |
