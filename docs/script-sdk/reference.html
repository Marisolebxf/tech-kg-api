常见错误对照

报错原因 → 解法
400 SemanticError: Unknown column 'X' in schema属性名不在 Tag/Edge schema → 核对 DDL；边可在写前 ensure_edge_schema 补列
400 Storage Error: data type does not meet the requirements给 string 列传了 int/float → 写入层已统一 stringify；自查是否绕过了 write_records
边大量 missing_source / missing_target实体脚本没先跑，或端点 VID 公式与实体侧不一致 → 先跑实体脚本；端点公式一律 import
重跑后点/边翻倍VID/rank/identity 不确定 → 检查是否用了自增序号/时间戳/未归一化文本参与身份
cannot render an empty edge insert / 属性签名不一致rank 通道同批属性键不一致 → mapper 属性集固定，动态键改走 merge 通道
merge 通道边 upsert 不去重缺 source_record_id 属性 → edge_provenance() 自带；自定义 identity 显式传
workflow 路径参数不生效build_parser 与 common_args_from_payload 镜像漂移 → 对照两个函数确认 key 一致
