## 踩坑记录(选数时规避的坑)

1. **合作网络空壳点**:演示批 `COAUTHOR_WITH` 邻居绝大多数是无 Person 属性的空壳顶点(如 person_G6855931 等),模块按 VID 取节点详情会失败——合作对必须双端可 `FETCH` 出属性。
2. **演示论文无年份**:paper_9xxxx 短 id 论文无 `publication_year`/`title`,模块三/六给时间窗时这些成果会被整体排除——必须走 dwd 真实论文对。
3. **财务事件集中在 2025 年**:节点事件的 stock_finance/annual_finance 的 occur_date 都是 2025(年报 2025、上市财务 202512),时间窗不含 2025 会查出 0 条。
4. **人工智能链无节点**:chain_IC9902 存在但无任何 IndustryNode,全景图 industry 传「人工智能」会退化为关键词兜底;可用链只有集成电路与低空经济。
5. **远端 dev 空间零索引**:LOOKUP 类标签检索会 IndexNotFound;本批入参全部走 VID 直取路径,不受影响。
6. **校友 fixture 池有限**:`STUDIED_AT` 仅 96 条且全在 9F9A fixture 批,换学校不换批次即可(上交/浙大/华科/复旦/燕山均有余量)。
