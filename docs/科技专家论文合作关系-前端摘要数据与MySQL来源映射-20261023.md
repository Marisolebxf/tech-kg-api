## 一、前端摘要区:12 行字段与空态渲染

渲染链路:`BusinessServiceView.vue` → `components/BusinessServiceAlgorithmPanel.vue`;行标签来自 `service-modules.ts` 的 `summaryRows`(paper-cooperation 节,12 行),值来自 `buildLiveSummary()`(该文件 2480-2514 行)按标签覆写。M6 不在 `isLiveModule` 集合(仅校友/两点成果/同事),故 `liveSummaryRows` 恒 null、静态 12 行标签始终承载布局:未执行查询时 12 行标签配空值;查询失败(`liveResponse=null`)时摘要区整块清空(`detailRows` 对 M6 直接返回 `[]`),错误走 toast。

| 摘要行 | 绑定 structuredResult 字段 | 渲染逻辑 | 空态文案(何时出现) |
|---|---|---|---|
| 核心专家 | `authorList[0]`+`authorUnits[0]` | `名`+有单位时拼`｜单位`;单位空串不拼尾巴 | `-`(authorList[0] 空时) |
| 合作专家 | `authorList[1]`+`authorUnits[1]` | 同上 | `-` |
| 作者单位 | `authorUnits` | `filter(Boolean).join("；")` | `-`(两元素均空串/空数组) |
| 合作发表时间 | `cooperationTimeRange.displayText` | 原样显示(`YYYY - YYYY`) | `暂无数据`(displayText 空串,即任一年份缺失) |
| 论文主题 | `paperTopics` | 前 4 项 `、` 连接 | `-`(空数组) |
| 合作论文数量 | `cooperationPaperCount` | `N 篇` | 无空态,恒显示(`0 篇`) |
| 期刊/会议级别 | `journalLevelCount`+`conferenceLevelCount` | 两对象合并逐项 `级别 N 篇`、`、` 连接(同键会议覆盖期刊) | `暂无分级数据`(两对象均为空/全为「未分级」以外无键;仅剩 `未分级` 键时显示 `未分级 N 篇`) |

## 二、structuredResult 逐字段 → 图查询映射

服务调用链一次请求内的图查询(均走 graph-search 端点,`space=dev`):

| 图查询 | 端点 | dev 空间实际形状 |
|---|---|---|
| 专家点×2 | `GET /graph-search/nodes/{vid}` | `FETCH PROP ON * person_xxx`(节点不存在→404 整个接口 404) |
| 共同论文路径 | `POST /graph-search/paths/search` | `MATCH (n0:Person)<-[e0:AUTHORED_BY]-(n1:Paper)-[e1:AUTHORED_BY]->(n2:Person) WHERE id(n0)=="A" AND id(n2)=="B" [AND n1.Paper.publication_year>="起" AND <="止"]`,按论文 VID 去重,翻页 200/页,上限 1000 篇 |
| 逐篇上下文 | `GET /graph-search/filtered-subgraph/{paper_vid}`(DOI 含 `/` 的 VID 回退逐类型 `/subgraph`) | 一跳合并取 `AUTHORED_BY`(出)/`PUBLISHED_IN`(出)/`HAS_KEYWORD`(出),拆回三类;`CITED_BY`(出)按需单拉 |
| 聚合兜底(仅无时间条件且未命中论文时) | `POST /graph-search/paths/search` | `COAUTHOR_WITH` 出向 1 跳(直连合作数)+2 跳(共同合作者) |
| 预计算合作者(仅命中论文且第三方合作者<3 时) | `GET /graph-search/subgraph/{A}` | `PAPER_COOPERATED_WITH` both;**dev 空间此边不存在**,查询 400 被吞、静默跳过 |

字段映射(兜底顺序自上而下):

| structuredResult 字段 | 图依赖 | 聚合/兜底 |
|---|---|---|
| `authorList` | Person.`name_zh`→`name_en`(两位专家点属性) | 取不到名时回退请求入参原串 |
| `authorUnits` | Person.`scholar_org_name_zh`→`scholar_org_name_en`→`scholar_org`→`extra_json.affiliation`(JSON 字符串/列表取第一个非空) | 全空→空串`""`(dev 无前两列,实际只走后两级) |
| `cooperationTimeRange` | Paper.`year`→`publication_year`→`publish_date|publication_date[:4]`(dev 只有 `publication_year`/`publication_date`) | 逐年取 int 失败记 0;全部为 0→startYear/endYear=0、displayText=`""` |
| `paperTopics` | Keyword 点 `keyword`→`name`(HAS_KEYWORD 对端),按出现次数 Counter 取前 8 | 空→两位专家 Person.`research_fields`(分号拆分)交集+并集前 8(仅学者库专家有此属性) |
| `cooperationPaperCount` | 共同论文路径去重计数 | 无时间条件且 0 篇→`COAUTHOR_WITH.co_paper_count` 直连边最大值 |
| `cooperationFrequency` | 同上 | 恒等于 cooperationPaperCount |
| `journalLevelCount` | 逐篇取 `PUBLISHED_IN` 第一个对端 Journal 点分级(非会议论文时计数):`venue_level`→`jcr_zone`(JCR-x)→`scope_zone`(中科院-x)→`sub_quartile`(分区-x)→`top`(Top期刊)→`is_sci`(SCI)→`zh_core` | 无期刊对端→「未分级」桶 |
| `conferenceLevelCount` | 同上,但仅 Paper.`venue_type`→`publication_type`→`document_type` 含 conference/proceedings/会议/cvpr/iccv/eccv(判为会议)时计入 | dev 无 `venue_type` 列,`publication_type` 实测恒空→**恒为空对象** |
| `citation.total`/`max` | 逐篇三级:①Paper.`citation_count`(dev **无此列**,恒空)→②该篇 AUTHORED_BY 边 `citations` 取最大→③`CITED_BY` 出边按 `citation_identifier`(缺失取对端 VID/边 id)去重计数 | ①②任一>0 时连 CITED_BY 子图都不拉;total=逐篇求和,max=逐篇最大 |
| `stableTeamMembers` | ①第三方合作者(逐篇 AUTHORED_BY 对端,排除两位专家)按「共文数≥2 且覆盖≥2 年」取前 5;②空且 `PAPER_COOPERATED_WITH.structured_result.stableTeamMembers` 有值(边不存在,失效);③空且论文≥2 篇且跨≥2 年→两位专家本身 | 全不满足→空数组 |
| `stableTeamNote` | 无稳定团队时的原因文案:仅 1 篇/同年多篇/仅聚合统计缺逐篇年份/时间范围内无共同论文 | 有稳定团队→空串 |
| `coreCollaborators` | 第三方合作者按共文次数排序取前 5;末尾强制追加两位专家本名(去重) | 无第三方也至少返回对方二人 |
| `sharedContribution` | 有论文→`联合论文产出`;total>0→`持续学术影响`;两人单位串不同→`跨机构协同研究`;有主题→`{首主题}共同研究` | 无论文→空数组 |
| `academicImpactScore` | `min(99.5, round(论文数×6.5 + 总被引/max(18, 论文数×3) + 已分级论文数×4))`;已分级=两 Count 中除「未分级」外全部求和 | 无论文→0.0 |
| `relationConfidences` | paperCooperation=基础 0.75(有逐篇路径)/0.65(仅聚合边)+min(论文数,4)×0.05+跨年 0.05;authorship=1.0/0.85/0;authorUnit=2 单位 1.0、1 单位 0.5;researchTopic=有边 1.0、仅回退 0.8;publicationVenue=有期刊证据论文占比;teamMembership=稳定团队时合作分+0.05 | 全部封顶 1.0,无证据 0.0 |

另:`graph`(画布)与 `provenance`(证据)为响应平级字段,不属摘要;provenance 逐节点由 `record_node_source` 透传血缘(第四节)。

缺失/注意项汇总:

1. **conferenceLevelCount 恒空**(无会议数据通道):要让它出数,需 Paper 有会议类 venue 且 `venue_type`/`publication_type`/`document_type` 含会议标记,当前 dev schema 无 `venue_type` 列、`publication_type` 实测全空。
2. **被引第①级 Paper.citation_count 列在 dev 不存在**;真实被引依赖 AUTHORED_BY.citations 回填(目前仅个别测试对)或 CITED_BY 边(dwd_zh_paper_citation 全库 2,032 行/图 2,558 边)。演示批三组均走 CITED_BY 计数(M6-1 3+2+1=6、M6-2 1、M6-3 2,与响应一致)。
3. **PAPER_COOPERATED_WITH 边不存在**→预计算核心合作者/稳定团队兜底恒跳过(dev 无副作用,仅代码路径死)。
4. Person 单位前两级列名(scholar_org_name_zh/en)与 fallback 年份键(work_start_year/work_end_year)在 dev 均为死路径;单位实际来源=`scholar_org`(学者库)或 `extra_json.affiliation`(论文作者批)。
5. `academicImpactScore`/`cooperationFrequency` 后端有值但前端摘要区不显示;如需展示属前端改动,无数据缺口。
6. 时间过滤为 `publication_year` 字符串按年比较(入参只取前 4 位),月日粒度不参与过滤(M6-2 窗口 2022-01~2022-12→仅命中 2022 年 2 篇,2024 年第 3 篇被滤,已实测)。
