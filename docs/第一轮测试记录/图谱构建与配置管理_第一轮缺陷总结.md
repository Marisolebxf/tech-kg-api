## 一、配置管理（79 条不通过）

涉及页面：**语言模型、向量模型、MySQL 数据源**（每页都有「新建配置」表单 + 「管理」详情抽屉两套表单）、**图数据空间**（新建弹窗）。
主要前端文件：`frontend/src/views/platform/ConfigurationManagementView.vue`

### 1. 超长输入未做即时长度校验（约 40 条，最大簇）

统一预期：**输入超过上限的第 N+1 个字符时立即触发校验**，字段位置提示「输入长度不能超过 X 个字符」，无需点提交即可发现；**恰好等于上限的边界值必须能完整接收、不截断**（127/128、255/256、499/500 等边界用例也失败了，说明现有 maxlength 缺失或设错）。

各字段长度上限：

| 字段 | 上限 | 涉及用例（FUNC- 后缀） |
|---|---|---|
| 配置名称 / 模型 / 用户名 / 默认库 / 详情模型 | 128 | 00404, 00443, 00478, 00507~00509, 00521, 00522, 00529, 00543, 00557, 00590, 00616, 00623 |
| Base URL / 主机 / API Key / 更新API Key / 更新密码 | 256 | 00423, 00485, 00513~00515, 00527~00529, 00549, 00550, 00574~00576, 00596, 00597, 00630 |
| 说明（新建表单） | 200 | 00430, 00492 |
| 配置说明（详情抽屉） | 500 | 00535, 00536, 00581~00583, 00637 |
| 端口 / 维度 / 批大小（数字输入） | 64 位数字 | 00417, 00462~00464, 00610 |
| 图数据空间名称 | 64 | 00676 |

### 2. 异常字符 / XSS 输入未触发安全校验（约 23 条）

输入 `<script>alert(1)</script>`（主机/默认库用 `127.0.0.1;<script>`、`gkx_element;<script>`）时：
- 应立即显示异常字符/格式校验状态（输入即校验，不需提交）；
- 不得执行脚本、破坏页面结构或形成未转义请求；
- 连接测试应失败并显示原因，异常值不得保存为可用配置；
- 密码/API Key 类字段按密码控件隐藏明文，凭据仅作安全字符串提交。

用例：00405, 00424, 00431, 00444, 00452, 00471, 00479, 00486, 00493, 00509, 00523, 00537, 00544, 00551, 00558, 00577, 00584, 00591, 00598, 00617, 00624, 00631, 00638

### 3. 范围 / 边界校验缺失（5 条）

- **维度** 输入 0 或 8193 应拒绝（有效范围 1–8192）：00407, 00412（新建）、00560, 00565（详情）
- **端口** 输入 0 应拒绝（1–65535）。测试方特别注明：**「当输入 0 时前端当前取值逻辑可能回退为 3306，应核对最终提交值」**：00454
- 端口 63/64 位数字应可正常输入且继续按 1–65535 业务校验、控件无卡顿：00462, 00463

### 4. 必填校验未拦截提交（3 条）

预期：必填字段为空时表单不提交、字段位置显示必填提示、不产生数据变更。
- MySQL 数据源「用户名」为空：00473
- 向量模型详情抽屉「模型」为空：00553
- 图数据空间「名称」为空：00672

### 5. 功能性缺陷（2 条）

- **00377 语言模型「验证连接」**：合法配置点验证后，应显示「验证中…」→「验证成功，延迟 X ms，可以保存」，且「保存」按钮变为可用
- **00382 语言模型「设为默认」**：应提示已设为默认、目标配置显示默认标识、**同类别原默认配置自动取消默认**

### 修复建议（一次封装、多表单复用，可关掉约 70 条）

在 `ConfigurationManagementView.vue` 里为三个配置类型（新建 + 详情抽屉共 6 套表单）统一封装字段校验规则：`maxlength`/数字位数 + 输入即触发（`@input`）的长度与字符白名单校验 + 范围校验 + 必填校验。注意后端已有 `biz/schemas/text_rules.py`（64 字符 + 字符白名单的共享校验），但本次各字段上限是 128/256/500/64 不等，**需要按字段定制长度**，不能直接套用 64 字符规则；安全校验口径可复用其字符白名单思路。

## 二、图谱构建（7 条不通过）

主要前端文件：`frontend/src/views/platform/GraphBuildView.vue`；后端抽取/调度链路：`service/temporal_workflows.py`、`script/run_temporal_worker.py`

### 前端交互（3 条）

- **00843 任务状态筛选选「未选择」**：应清空状态筛选、列表展示其他条件下全部任务、不触发接口参数异常（实测失败，有截图）
- **00847 任务类型筛选选「未选择」**：同上
- **00872 新建抽取任务「批大小」**：连续输入 65 位数字应触发 64 字符长度限制，第 65 位不得进入有效值（有截图）

### 后端 / 调度（4 条，均附实测记录）

- **00918 抽取结果写入图谱**：抽取成功后「查询与服务→实体列表」检索不到本次写入的实体（实测记录：**搜索不显示内容**）；平台总览统计应更新；同名实体应进入 T_LINK 对齐裁决而非直接覆盖 → 需排查 抽取写入 → 图空间 → 实体列表检索 链路
- **00919 抽取失败人工审核联动**：失败批次应生成 T_EXTRACT_FAIL（OPEN, attempt=1）待处理记录，失败记录数量如实统计、超上限截断建案但计数不变（实测记录：**没有如实统计数据**）
- **00921 周期任务自动触发**：周期性任务（如每天 HH:MM）到点应自动产生执行、触发方式显示「定期触发」并按频率顺延（实测记录：**没有按时自动触发**）
- **00929 连续两个调度周期**：两个调度点各生成一条执行记录、实际触发时间与 cron 预览一致、水位延续不重复抽取（与 00921 同根因，疑似调度器/cron 未生效）

---

## 三、建议修复优先级

1. **配置管理表单校验封装**（约 70 条，纯前端，收益最大）
2. **周期调度不触发**（00921/00929，功能性 P1，影响定时抽取）
3. **抽取结果检索不到**（00918，抽取→查询链路数据一致性问题）
4. 失败统计如实性（00919）、「未选择」筛选清空（00843/00847）、批大小长度校验（00872）、验证连接/设为默认交互（00377/00382）
