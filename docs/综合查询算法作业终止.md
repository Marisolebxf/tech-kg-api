# 综合查询算法作业终止

PageRank、Louvain、Degree 共用“终止算法作业”按钮，位于提交按钮之后。只有当前页签有运行中的作业时可点击；请求期间禁用重复点击；切换页签不会取消其他页签的作业。取消失败显示后端原因并恢复轮询。

## 后端接口

`POST /api/v1/graph-algorithms/jobs/{jobId}/cancel?space={graphSpace}`

沿用登录身份、空间访问检查和远程作业空间归属检查。已完成的作业保持原状态及结果。

- Degree：Redis 保存独立终止标记，支持提交与取消落到不同 API worker。后台在查询、会话排队、索引等待和重试边界检查标记；取消后不再提交后续查询或发布结果。已发出的图库查询需等待返回或超时；不会中断其他作业共享的索引重建。
- PageRank/Louvain：终止通道二选一（`TRSGRAPH_ALGORITHM_RUNNER_URL` 优先）。单机部署向图算法 runner 发 `POST /jobs/{jobId}/kill`（runner 杀 spark-submit 子进程，终态 `cancelled`）；Spark Standalone 部署读取当前作业的 `submissionId`，向配置的 master 发出单 driver 的 `POST /v1/submissions/kill/{submissionId}`，校验返回的 `success` 和标识。接受终止请求后继续轮询，直到终态为 `cancelled`（runner）或 `driverState=KILLED`（Spark）才显示“已终止”。

## 部署配置

PageRank/Louvain 终止通道按部署形态二选一（同时配置时 runner 优先）：

**单机 all-in-one 部署（算法经 trsgraph-algorithm-runner 以 Spark local 模式执行，无 standalone master）**：

```dotenv
TRSGRAPH_ALGORITHM_RUNNER_URL=http://trsgraph:8091
```

- runner 需为加入 `POST /jobs/{id}/kill` 端点的版本（源码副本：tech-kg-db 仓库
  `docker/algorithm-runner/runner.py`，经卷挂载覆盖镜像内文件）。
- runner 收到 kill 后向 spark-submit 子进程发 SIGTERM，并在内部 killRequested
  标记下把终态定格为 `cancelled`（晚到的成功快照不能复活作业）；
  接受终止 ≠ 已终止，前端继续轮询至 `cancelled`。
- 该地址未发布宿主机端口：后端容器需接入图库网络（dev2 compose 已通过
  external network `tech-kg-db_default` 接入）。

**Spark Standalone 部署（新架构）**：在后端环境或 Docker Compose 的环境文件中添加实际 master REST 地址：

```dotenv
GRAPH_ALGO_SPARK_REST_URL=http://<实际Spark-master主机>:6066
```

Spark master 需启用 `spark.master.rest.enabled`，地址需能从后端容器访问。读取当前作业的 `submissionId`，向 master 发出单 driver 的 `POST /v1/submissions/kill/{submissionId}`。

两条通道均未配置时取消接口返回 503 和明确提示，作业仍保持运行。Degree 不依赖这些地址，但需要 Redis 保存跨 worker 终止标记。

Spark 接口依据：[Spark 3.5.4 standalone REST API](https://spark.apache.org/docs/3.5.4/spark-standalone.html#rest-api)。现有图算法服务需在轮询快照中提供 `submissionId` 和 `driverState`（客户端已有对应字段）。上线前需在真实环境验证这两项及终止后引擎释放作业槽位。

## 结果表格和 CSV

nGQL 与三个算法复用独立纵向滚动的结果表格。表头保持可见，横向滚动条位于可视表格底部，悬停或滚动时显示，样式与人工审核一致。详情为左对齐文字按钮，悬停无填充背景；刷新状态复用重新检测按钮样式。

算法 CSV 保留服务端返回的全部结果（包含预览截断的返回行），首列新增“序号”，从 1 连续编号；保留 UTF-8 BOM、引号转义和公式字符保护。
