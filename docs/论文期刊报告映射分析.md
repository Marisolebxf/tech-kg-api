# 论文/期刊/报告 图数据库映射分析文档

> 本文档分析 gkx_element 数据库中论文、期刊、报告相关表的每个字段，如何映射到图数据库（TRSGraph dev 空间）中的实体（Tag）和关系（Edge）的属性上。
> 参考本体设计：`ontology.md`；参考整体映射：`mapping.md`。

## 1. 图空间与命名

| 项 | 值 |
|---|---|
| 图空间 | `dev` |
| VID 格式 | `paper_{id}`, `person_{author_id}`, `journal_{publication_id}`, `report_{report_id}` |
| 属性类型 | 全部 `string`（避免 nGQL INSERT 时 int/string 类型不匹配） |

## 5. ETL 脚本

| 脚本 | 作用 |
|---|---|
| `backend/script/init_paper_journal_schema.py` | 创建 dev 空间 + Tag/Edge DDL |
| `backend/script/load_paper_journal_graph.py` | 从 gkx_element 读取数据 → INSERT 到 dev 空间 |

### ETL 关键技术点

1. **nGQL 前缀**：所有语句需 `USE dev;` 前缀（trs-graph DDL 不认 X-Graph-Space header）
2. **单条 INSERT**：trs-graph 不支持多值 INSERT，每次 1 条
3. **全 string 属性**：Tag/Edge 属性全部 string，避免 int/string 类型不匹配
4. **空间传播延迟**：CREATE SPACE 后等 30s，CREATE TAG 后等 15s
5. **占位节点**：参考文献/引用的目标论文不在库内时，创建占位 Paper 节点（`paper_ref_{md5(doi)}`）

## 7. 图库查询指南

### 7.1 可视化工具

TRSGraph Studio 已在 `http://localhost:7001` 运行，浏览器打开后选择图空间 `dev`，在查询框输入 nGQL 即可。

**核心规则**：`RETURN` 节点/边本身（`n`、`e`、`p`、`a`）会渲染成**图**；`RETURN` 属性（`n.title`）只出**表格**。

| 写法 | 效果 |
|---|---|
| `RETURN p, e, a` | 出图（节点+边可视化） |
| `RETURN p.Paper.title_zh, a.Person.name_zh` | 出表格（只有属性值） |
| `RETURN count(n)` | 出数字 |
| `GET SUBGRAPH N STEPS FROM "vid"` | 出子图（N跳范围内全部点和边） |

### 7.2 可视化查询 nGQL

在 TRSGraph Studio 查询框中直接输入以下语句（Studio 会自动加 `USE dev;`，手动调用 API 时需加前缀）：

```ngql
-- 1. 看某篇论文的作者（1跳：论文→作者）
MATCH (p:Paper)-[e:AUTHORED_BY]->(a:Person)
WHERE id(p) == "paper_1002153099575427075"
RETURN p, e, a

-- 2. 看某篇论文的完整关系网（2跳：论文→作者→其他论文 + 论文→期刊）
MATCH (p:Paper)-[e]-(n)
WHERE id(p) == "paper_1002153099575427075"
RETURN p, e, n

-- 3. 看子图（从某节点出发，2跳范围内的所有点和边）
GET SUBGRAPH 2 STEPS FROM "paper_1002153099575427075"

-- 4. 随机看 20 条论文-作者关系
MATCH (p:Paper)-[e:AUTHORED_BY]->(a:Person)
RETURN p, e, a LIMIT 20

-- 5. 看论文-作者-期刊三角关系
MATCH (p:Paper)-[:AUTHORED_BY]->(a:Person),
      (p)-[:PUBLISHED_IN]->(j:Journal)
RETURN p, a, j LIMIT 20

-- 6. 看论文→参考文献（CITES）关系
MATCH (p:Paper)-[e:CITES]->(r:Paper)
RETURN p, e, r LIMIT 20

-- 7. 看 3 跳路径：论文A → 共同作者 → 论文B
MATCH (p1:Paper)-[:AUTHORED_BY]->(a:Person)<-[:AUTHORED_BY]-(p2:Paper)
WHERE id(p1) == "paper_1002153099575427075" AND id(p1) != id(p2)
RETURN p1, a, p2 LIMIT 20

-- 8. 看某期刊发表的所有论文
MATCH (p:Paper)-[e:PUBLISHED_IN]->(j:Journal)
WHERE id(j) == "journal_2064"
RETURN p, e, j LIMIT 20

-- 9. 看报告节点样例
MATCH (r:Report)
RETURN r LIMIT 20
```

### 7.3 API 查询（curl / Python）

**连接信息**：

| 项 | 值 |
|---|---|
| API 地址 | `POST http://localhost:8090/api/v1/query/write` |
| 认证 | Header `X-API-Key: ysukeg` |
| 请求格式 | `{"query": "USE dev; 你的nGQL语句;"}` |
| 图空间 | `dev`（所有语句需 `USE dev;` 前缀） |

**查节点（点）**：

```bash
# 查所有 Tag 类型
curl -s -X POST http://localhost:8090/api/v1/query/write \
  -H "X-API-Key: ysukeg" -H "Content-Type: application/json" \
  -d '{"query":"USE dev; SHOW TAGS;"}' | python3 -m json.tool

# 查 Paper 总数
curl -s -X POST http://localhost:8090/api/v1/query/write \
  -H "X-API-Key: ysukeg" -H "Content-Type: application/json" \
  -d '{"query":"USE dev; MATCH (n:Paper) RETURN count(n) AS cnt;"}' | python3 -m json.tool

# 查 Paper 样例（前 10 条，返回标题/DOI/年份）
curl -s -X POST http://localhost:8090/api/v1/query/write \
  -H "X-API-Key: ysukeg" -H "Content-Type: application/json" \
  -d '{"query":"USE dev; MATCH (n:Paper) RETURN id(n) AS vid, n.Paper.title_zh AS title, n.Paper.doi AS doi, n.Paper.publication_year AS year LIMIT 10;"}' | python3 -m json.tool

# 按 DOI 查某篇论文
curl -s -X POST http://localhost:8090/api/v1/query/write \
```
