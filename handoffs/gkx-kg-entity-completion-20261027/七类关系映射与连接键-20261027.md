# 七类关系映射与连接键

核对：`gkx_kg-full-20261024 (1).sql.gz`；日期：2026-10-27。

表中使用实际业务主键；`→` 表示起终点，不表示两个字段直接相等。

| 关系 | 名称 | 起点实体 → 终点实体 | 连接键（gkx_kg 表.id） | 说明（间接分析得到的） |
| -- | -- | ----------- | ---------------- | ----------- |
| `HAS_NEWS` | 机构关联新闻 | `Organization → News` | `kg_organization.org_id → kg_news.news_id` | 直接 |
| `HAS_NODE` | 产业链包含节点 | `IndustryChain → IndustryNode` | `kg_industry_chain.chain_code → kg_industry_node.node_id` | 直接 |
| `HAS_OUTPUT` | 项目产出成果 | `Project → Paper / Patent / Report` | `kg_project.id → kg_paper.id / kg_patent.patent_id / kg_report.report_id` | 展开产出；论文按 DOI→题名＋年→题名，专利按号码→题名，报告按题名＋年→题名匹配。 |
| `HAS_PARTICIPANT` | 项目参与人 | `Project → Person` | `kg_project.id → kg_person.person_id` | 拆 `participants`，按人物姓名或 `source_record_id` 唯一匹配。 |
| `INVENTED_BY` | 专利发明人 | `Patent → Person` | `kg_patent.patent_id → kg_person.person_id` | 姓名与任职机构筛出唯一学者；项目证据仅加分。 |
| `INVESTS_IN` | 机构投资 | `Organization → Organization` | `kg_organization.org_id → kg_organization.org_id` | 直接 |
| `INVOLVED_IN` | 机构参与事件 | `Organization → Event` | `kg_organization.org_id → kg_event.event_id` | 直接 |

匹配规则：候选须唯一才确认；成果匹配零命中可降级，多命中停止。发明人未确认项交平台后续处理。

补数范围：链归属、项目产出/参与人、发明人和投资明细依赖真实来源；当前备份缺 `kg_report`。来源缺失或身份不明时跳过，不补造实体或关系。

补充 SQL 仅补实体表、字段和有来源的数据，不建七张关系表、不含模拟业务样例。明确测试标记会跳过；原库已有测试记录不会自动清除。

代码依据：[关系抽取代码](https://github.com/Marisolebxf/tech-kg-api/tree/0c223938819902103ec2b715108d2e5dd5b453a2/backend/script/relation_extractors_one_relation)、[成果匹配规则](https://github.com/Marisolebxf/tech-kg-api/blob/0c223938819902103ec2b715108d2e5dd5b453a2/backend/script/project_entity_matcher.py#L222-L260)。
